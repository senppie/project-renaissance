# PROJECT:RENAISSANCE

PROJECT:RENAISSANCE is a modern website created as a digital tribute to Beyoncé’s RENAISSANCE album. It reimagines the album’s original visual identity through a contemporary design approach, transforming its aesthetics into an immersive digital experience for fans to explore and appreciate the artistry behind the era.

## Vision
A high-fidelity, dark-themed visual exploration that pays homage to the RENAISSANCE album, combining minimalist design with a sophisticated user interface.

## Features
- Discover the album’s tracklist, singles, and key releases from the RENAISSANCE era.
- Explore a curated visual collection featuring imagery from the RENAISSANCE album and world tour.
- Experience a custom online store with a dedicated shopping and checkout experience, featuring merchandise inspired by the album’s visual identity.

## Running the Project

1. Clone the repository by running the following command in your terminal:

```bash
git clone https://github.com/senppie/project-renaissance.git
```

2. Open the project by opening `index.html` in a modern web browser. No build step is required.


Alternatively, you can access the live website [here](https://senppie.github.io/project-renaissance/).

## Technical Stack
- Styling: Tailwind CSS v4 for responsive layouts and visual styling.
- Frontend: HTML5, CSS3, and JavaScript for the website’s structure, presentation, and interactivity.
- Architecture: Modular, component-based structure for reusable navigation, branding, and shopping components.

## Project Structure

| Directory / File | Description |
| :--- | :--- |
| `assets/` | Images, fonts, icons, and other visual resources. |
| `components/` | Reusable UI components, including navigation, hero sections, and shopping cart elements. |
| `index.html` | Main landing page introducing the project. |
| `music.html` | Album tracklist, singles, and music-related information. |
| `visuals.html` | Visual gallery featuring imagery from the album. |
| `tour.html` | Visual gallery showcasing imagery from the RENAISSANCE World Tour. |
| `shop.html` | Online store featuring RENAISSANCE-inspired merchandise. |
| `checkout.html` | Shopping cart and checkout interface. |
| `credits.html` | Project credits and acknowledgments. |
